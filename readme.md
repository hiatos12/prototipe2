## ✨ Features

- 🖥️ Desktop-style UI with boot animation
- 🪟 Draggable & resizable windows
- 🔝 Dynamic window focus & `z-index`
- ⌨️ Keyboard shortcuts
- 📁 Virtual File System
- 📂 File Manager with navigation & history
- 📝 Text Editor
- 💻 Terminal
- 🎵 Functional Music Player
- 🎬 Functional Video Player
- ⚙️ Settings
- 🕒 Live clock & date

```bash

cd Web-OS
````

Open `index.html` in your browser.
